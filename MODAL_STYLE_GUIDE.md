# Modal Style Guide

All modals should follow these consistent styling patterns:

## Title
- **Font**: `font-display text-2xl font-medium text-slate-900`
- **Spacing**: `mb-2` or `mb-4` depending on context

## Body Text
- **Font**: `text-base text-slate-600`
- **Line Height**: Default (leading-relaxed if needed)

## CTA Buttons
- **Primary Button**: 
  - `bg-slate-900 hover:bg-slate-800 text-white`
  - `px-8 py-4 text-base font-semibold rounded-xl`
  - `shadow-lg hover:shadow-xl`
  
- **Secondary/Cancel Button**:
  - `bg-slate-100 hover:bg-slate-200 text-slate-700`
  - `px-8 py-4 text-base font-semibold rounded-xl`

## Alignment & Spacing
- **Container**: `p-6` or `p-8` for content padding
- **Button Container**: `flex justify-end gap-4 mt-6`
- **Title + Body**: `mb-6` or `mb-8` for spacing between header and content

## Modal Structure
- **Backdrop**: `bg-black/50 backdrop-blur-sm`
- **Modal**: `bg-white rounded-2xl shadow-2xl`
- **Max Width**: `max-w-md` or `max-w-lg` depending on content
